# UniOS Learning Intelligence (AI/ML-2)

Service responsible for understanding the learner and generating adaptive pedagogy, structured lessons, learner memory intelligence, and roadmap adaptation for the UniOS ecosystem.

---

## Architectural Role & Ownership Boundaries

- **AI/ML-2 (This Service) Owns:**
  - Learner Profile & Onboarding Intelligence
  - Multi-Facet Learner Memory Intelligence
  - Context Retrieval & Evidence-Driven Memory Updates
  - Pedagogical Decisions & Adaptive Lesson Generation
  - Roadmap Adaptation Intelligence
- **AI/ML-1 Owns:** KIE core orchestration, intent routing, agent coordination, and roadmap planning execution.
- **Backend Owns:** User authentication, authorization, and persistent database storage.
- **Frontend Owns:** Client UI rendering and `LessonRenderer` (no raw UI code generated by AI/ML-2).

---

## Sprint 3 Capabilities: Memory Engine + Context Retrieval

### 1. The 7 Memory Dimensions
Located in `app/schemas/memory.py`:
1. **Preferences**: Cognitive modalities (visual, hands-on, theoretical, interactive), pacing velocity, practical vs. theory ratio, and feedback frequency.
2. **Conversations**: Q&A signals, sentiment markers (curious, confused, frustrated), and concept confusions.
3. **Learning History**: Completed units, assessment scores ($0.0 - 1.0$), attempts, time spent, and mastery levels.
4. **Projects**: Practical projects attempted/completed, technologies used, and complexity tiers.
5. **Goals**: Primary target career role, timeline in months, milestone checklists, and goal change audit log.
6. **Achievements**: Auto-awarded and milestone badges (mastery, streak, project completion).
7. **Friction**: Unresolved struggles, error compounding, severity tiers (low, moderate, high), and pedagogical intervention recommendations.

### 2. Evidence-Driven Memory Updates
Located in `app/schemas/memory_events.py` & `app/services/memory_engine.py`:
- **Credibility Classification**: Distinguishes `explicit` declarations, `observed` platform telemetry, and `inferred` heuristic signals with confidence scores ($0.0 - 1.0$).
- **Friction Escalation & De-escalation**: Low assessment scores (< 50%) or repeated mistakes compound friction severity; high assessment scores (> 80%) de-escalate and resolve prior friction.

### 3. Context Retrieval & Roadmap Adaptation
- **`POST /api/v1/memory/relevant-context`**: Retrieves topic-specific memory (preferences, active friction, related history, and projects) for learning decisions without dumping raw history.
- **`POST /api/v1/memory/roadmap-context`**: Evaluates active friction and mastery to provide roadmap intelligence (`on_track`, `needs_remediation`, `ready_for_advancement`, `goal_shifted`).

## API Endpoints Overview

| Area | Method | Endpoint | Description |
| :--- | :--- | :--- | :--- |
| **System** | `GET` | `/health` | Service health, active LLM provider, and model |
| **Learning** | `POST` | `/api/v1/learning/plan-lesson` | Pedagogy decision + structured lesson generation |
| **Learning** | `POST` | `/api/v1/learning/generate-lesson` | Structured lesson generation alias |
| **Onboarding** | `POST` | `/api/v1/onboarding/validate-profile` | Fast preflight profile validation & heuristics |
| **Onboarding** | `POST` | `/api/v1/onboarding/analyze` | Generates 6-D Learner Intelligence Report |
| **Onboarding** | `POST` | `/api/v1/onboarding/learner-intelligence` | Backward-compatible onboarding analysis alias |
| **Memory** | `POST` | `/api/v1/memory/events` | Ingests learning activity & executes memory update |
| **Memory** | `POST` | `/api/v1/memory/update` | Memory event update alias |
| **Memory** | `POST` | `/api/v1/memory/retrieve` | Retrieves full structured `LearnerMemory` container |
| **Memory** | `POST` | `/api/v1/memory/relevant-context` | Scoped relevant memory for a learning decision |
| **Memory** | `POST` | `/api/v1/memory/roadmap-context` | Roadmap progression and adaptation intelligence |
